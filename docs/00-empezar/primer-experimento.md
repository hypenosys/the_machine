# Primer experimento: dos sensores se contradicen

**Sin instalar nada.** Sensor A dice 85 °C a las 10:00. Sensor B dice 55 °C a las 10:00.

**Pregunta:** ¿sabemos la temperatura real? No. Sabemos que A reportó 85 °C y B reportó 55 °C. Son dos observaciones de reportes, no una verdad física confirmada.

**Prueba:** escribe dos explicaciones posibles, qué nueva medición solicitarías y qué acciones requerirían permiso.

**Aprendizaje:** una IA fiable conserva ambas fuentes, representa la contradicción y no transforma una hipótesis en un hecho. Este es un ejercicio didáctico, no un test de software ejecutado.
