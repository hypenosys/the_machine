# Empieza aquí — Sin saber programar

**No necesitas instalar nada ni crear una cuenta.**

Imagina que dos sensores dicen cosas distintas sobre una máquina. ¿Cómo puede una inteligencia artificial distinguir lo observado de lo sospechado? THE MACHINE investiga cómo construir sistemas que sepan qué saben, expliquen de dónde procede la información y no actúen sin permiso.

GitHub es solo el lugar donde guardamos estos documentos y el código. Puedes leerlos como un libro.

1. [Haz el primer experimento](primer-experimento.md).
2. [Consulta el glosario](../../GLOSSARY.md).
3. [Aprende cómo investigamos](../01-investigacion/metodologia.md).
4. [Descubre cómo puedes participar](../../CONTRIBUTING.md).

**Estado real:** investigación y diseño en curso. No existe una IA general terminada.
