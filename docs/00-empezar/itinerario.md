# Tu itinerario por THE MACHINE

Este itinerario no exige instalar software para las primeras cuatro etapas. Puedes saltar de nivel y regresar cuando lo necesites.

## Nivel 0 — Descubrir (15 minutos)
**Objetivo:** explicar qué es el proyecto con tus propias palabras.
Lee [Empieza aquí](README.md) y realiza [el experimento de los dos sensores](primer-experimento.md).
**Comprueba:** ¿distingues un dato observado de una explicación posible?

## Nivel 1 — Aprender el vocabulario (20 minutos)
Consulta el [glosario](../../GLOSSARY.md). Aprende qué significan repositorio, código, software libre, Git, GitHub, Rust, hipótesis y prueba.
**Comprueba:** ¿puedes explicar por qué leer un repositorio no requiere saber programar?

## Nivel 2 — Pensar como investigador (30 minutos)
Lee [la metodología](../01-investigacion/metodologia.md) y el [caso práctico](../01-investigacion/caso-practico.md).
**Comprueba:** ¿puedes formular una hipótesis que pueda ser refutada?

## Nivel 3 — Comprender el diseño (45 minutos)
Lee [diseñar antes de programar](../02-diseno/README.md) y el [contrato de evidencia](../02-diseno/contrato-evidencia.md).
**Comprueba:** ¿qué información necesitarías conservar para corregir una conclusión?

## Nivel 4 — Construir (posterior)
Rust, tests y herramientas solo después de documentar, investigar y aprobar contratos. Este material **aún no está desarrollado**.

## Nivel 5 — Auditar (posterior)
Reproducir benchmarks, inspeccionar dependencias y revisar amenazas. Este material **aún no está desarrollado**.

## ¿Y si no entiendo algo?
Es una señal útil para mejorar el proyecto. Consulta el [glosario](../../GLOSSARY.md) o sigue [cómo participar](../../CONTRIBUTING.md). No hace falta conocer la solución para reportar una dificultad.
