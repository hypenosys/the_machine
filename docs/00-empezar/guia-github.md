# GitHub explicado sin experiencia previa

**Puedes leer el proyecto sin instalar Git ni Rust.** El repositorio era público según la comprobación de GitHub del 21-10-2026; la visibilidad puede cambiar.

- **README:** la portada del proyecto.
- **Carpeta:** agrupa documentos relacionados.
- **Archivo .md:** texto con títulos, enlaces y listas; GitHub lo muestra formateado.
- **Commits:** historial de cambios.
- **Issues:** conversaciones sobre preguntas, tareas y problemas.
- **Pull requests:** propuestas de cambios que pueden revisarse antes de incorporarlas.
- **master:** nombre actual de la rama principal del proyecto.

## Tu primera visita
1. Abre la portada `README.md`.
2. Pulsa «Empieza desde cero».
3. Haz el primer experimento sin instalar nada.
4. Si no comprendes una palabra, abre el glosario.
5. Si detectas un problema y tienes acceso, abre una Issue.

No necesitas clonar, hacer fork, abrir terminal ni entender comandos para realizar estos pasos.

## ¿Qué es software libre?
Una licencia de software libre concede permisos específicos para usar, estudiar, modificar y compartir software. Que un repositorio sea visible no basta para concederlos. **En `master`, `LICENSE.md` ofrece CC BY 4.0 para documentación original y materiales no software cubiertos; los derechos de terceros y la licencia de software futuro siguen pendientes.**
