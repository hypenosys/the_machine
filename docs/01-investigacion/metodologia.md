# Método de investigación

**Estado: propuesto; investigación exhaustiva pendiente.**

Para cada afirmación guardar pregunta, fuente, fecha, tipo de evidencia, explicación alternativa, incertidumbre y criterio de falsación.

Etiquetas: OBSERVADO (fuente primaria), REPORTADO (declaración), INFERIDO (interpretación), PROPUESTO (diseño), VERIFICADO (prueba reproducible).

La serie es evidencia de comportamiento ficticio, no de algoritmos reales. Revisar episodios y fuentes primarias antes de afirmar cobertura canónica. Comparar soluciones simples con alternativas complejas y publicar resultados negativos.
