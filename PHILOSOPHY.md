# THE MACHINE — Philosophy

Document → Research → Design → Implement → Verify → Teach what was learned.

A person with no knowledge of GitHub or programming must be able to understand the project without installing anything. Technical rigor and evidence must remain available at every level. Never claim implementation, tests or research have been completed without reproducible proof.

All code and architecture decisions must be linked to a documented requirement, evidence and verification criterion. Minimize dependencies, not at the expense of security. Preserve negative findings.
