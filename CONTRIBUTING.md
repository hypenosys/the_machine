# Cómo participar sin saber programar

Puedes detectar una explicación confusa, corregir una errata, verificar una fuente, proponer un ejemplo o traducir. No necesitas conocer Rust.

**Participación:** el repositorio es públicamente accesible según la comprobación de GitHub del 21-10-2026. Puedes consultar sus Issues y explicar dónde te perdiste, qué esperabas entender y qué entendiste; para abrir un issue o PR necesitarás una cuenta y los permisos que GitHub exija. No necesitas conocer la solución. La visibilidad del repositorio puede cambiar y no implica permiso para fusionar cambios.

Quien programe deberá documentar el problema, investigar alternativas, diseñar, implementar, probar y adjuntar evidencias. Las contribuciones se revisan con respeto y lenguaje comprensible.
