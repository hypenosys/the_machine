# THE MACHINE

**Una inteligencia artificial que puedas comprender, cuestionar y construir.**

THE MACHINE es un proyecto de investigación y desarrollo inspirado en *Person of Interest*. Investiga cómo construir sistemas que distingan hechos de hipótesis, conserven memoria verificable, razonen y ejecuten únicamente acciones autorizadas.

> **No necesitas saber programar ni entender GitHub para empezar.**

## Cómo trabajamos

**Documentar → Investigar → Diseñar → Implementar → Verificar → Enseñar.**

Cada explicación comienza con un ejemplo cotidiano y puede profundizar hasta los contratos, código, experimentos y fuentes. Conservamos también los errores y resultados negativos.

## Estado honesto

Investigación canónica exhaustiva pendiente; arquitectura Rust preliminar; sin afirmaciones de pruebas o seguridad completadas que no tengan evidencia. No es una AGI terminada ni una herramienta de vigilancia masiva.

## ¿Qué es GitHub?

Es una web donde se guardan proyectos y sus cambios. Puedes leer los documentos como un libro, sin cuenta. Este repositorio es actualmente privado: para leerlo necesitas que se te conceda acceso.
