# Security Policy

## Supported Scope

THE MACHINE is currently in a **conceptual design and pre-implementation** phase (HOLD / No functional code in tree). Security issues in design specifications, threat models, tooling, or documentation are actively reviewed.

| Phase / Scope | Supported |
| ------------- | --------- |
| Design & Documentation (`main` branch) | :white_check_mark: |
| Experimental branches | :x: |

## Reporting a Vulnerability

We take the security of THE MACHINE seriously. If you identify a potential security issue, design weakness, or vulnerability in specifications or tools:

1. **Do not open a public GitHub issue.**
2. Use GitHub's **Private Vulnerability Reporting** feature on this repository if available.
3. Alternatively, report the issue privately to the project co-owners [@Axlfc](https://github.com/Axlfc) and [@TopperH4rley](https://github.com/TopperH4rley).
4. Please include:
   - A description of the issue or threat scenario.
   - Files, models, or specifications affected.
   - Potential impact or proof of concept.

We appreciate responsible disclosure and will coordinate remediation and acknowledgment before any public disclosure.
