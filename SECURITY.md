## Reporting a Vulnerability

THE MACHINE takes security seriously. If you discover a vulnerability or security flaw in the architectural specifications, threat models, or design artifacts:

1. **Do not create a public issue or discussion.**
2. Report the vulnerability privately via GitHub Security Advisories or privately contact the project co-owners ([@Axlfc](https://github.com/Axlfc) and [@TopperH4rley](https://github.com/TopperH4rley)).
3. Please include a clear description of the issue, affected documents or models, attack scenario, and potential impact.

### Response Commitment

- An initial acknowledgment will be provided within 48 hours.
- Regular updates will be shared as the issue is evaluated and addressed in accordance with [`docs/02-diseno/security/incident-response.md`](docs/02-diseno/security/incident-response.md).
